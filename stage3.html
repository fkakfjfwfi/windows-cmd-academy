互动 3 · 重定向符号解剖（1 号流、2 号流各奔前程）

    
每条命令都自带三条"水流"：stdin（0 号，输入）、stdout（1 号，正常输出）、stderr（2 号，错误输出）。重定向符号就是给水流改道的闸门。点一个符号看它改了哪条道。

    

      

      

      

    

  


  
  

    
实用组合技（背下来，天天用得上）

    

      
📝 一秒建文件

        
echo 第1行内容>新建.txt

        
echo 本来是打印，接上 > 就把文字直接写成文件。注意数字结尾的坑：echo abc 2>文件 里那个 2 会被当成"错误流重定向"。

      

      
🤫 全静默执行

        
某命令 >nul 2>&1

        
正常输出丢进 nul 黑洞，错误流 2 并进 1 也一起消失。脚本里只要结果不要输出时就这么写——成败看 %errorlevel%。

      

      
🔗 合并文件

        
type a.txt b.txt > 合并.txt

        
type 天生支持多个文件串联输出，接个 > 落盘，就是合并。比复制粘贴快十倍。

      

      
📋 结果进剪贴板

        
dir | clip

        
clip 是 Windows 自带的"剪贴板水槽"，任何命令接个 | clip，输出直接进剪贴板，随便粘到哪儿。

      

      
🔢 统计行数

        
type server.log | find /c /v ""

        
find 的 /c 是计数、/v 是反选、"" 是空串匹配一切行——三件套合体就是 wc -l（统计总行数），输出一个数字。

      

      
🔎 全盘找文件

        
dir /s /b C:\*.log 2>nul

        
/s 递归 /b 纯路径，配通配符全盘搜文件；2>nul 把"拒绝访问"的报错丢掉，结果干干净净。

🎯 本阶段动手任务（回到你的真电脑）

        
1. 随便找个日志/文本文件，跑一遍 type 文件 | findstr "关键词" | sort > 结果.txt，全程替换关键词三次；

           2. 分别执行 dir > a.txt 和 dir >> a.txt 两次，type a.txt 观察"覆盖"与"追加"的区别；

           3. 执行 dir C:\拒绝访问的目录 2> err.txt，看看错误流怎么单独抓；

           4. 试 dir | clip，然后去记事本 Ctrl+V——感受命令行直通剪贴板。
