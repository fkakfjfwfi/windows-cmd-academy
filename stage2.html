互动 3 · robocopy 场景生成器（一条顶十条的备份神器）

robocopy（Robust File Copy，健壮复制）是 Windows 自带的"复制界天花板"：断点续传、多线程、镜像同步、失败重试全都行。选一个你最可能遇到的场景，看命令应该怎么写、每个参数什么意思。

📋 robocopy 常用参数速查

参数作用备注
/E复制所有子目录（含空目录）最常用，没有之一
/MIR镜像：让目标和源完全一致会删除目标端多余文件，方向写反=灾难
/Z可重启模式（断点续传）大文件、网络复制必带
/MT:nn 线程并行复制默认 8，最大 128；海量小文件提速明显
/R:n /W:n失败重试 n 次、间隔 n 秒默认 /R:1000000！网络备份必改成小值
/XO只复制比目标新的文件增量同步
/XF 文件排除匹配的文件（支持通配符）/XF *.tmp
/XD 目录排除整个目录/XD node_modules
/LOG:文件把输出写进日志文件/LOG:copy.log，常配 /NP
/NP不显示每个文件的进度百分比日志更干净
/MOV /MOVE复制后删除源文件 / 连目录一起移动搬家用，同样没有回收站
冷知识：robocopy 的退出码 0~7 都算"成功"（0=没文件要复制，1=成功复制了文件，2=检测到多余文件……），≥8 才是真的出错。所以脚本里判断成败要写 if %errorlevel% LEQ 7，阶段⑥会用到。

互动 4 · 通配符实验室：* 与 ?

几乎所有命令都支持通配符：* 代表任意长度的任意字符，? 代表恰好 1 个字符。点预设或自己输入模式，看哪些文件会被命中。

三代复制命令怎么选？

能力copyxcopyrobocopy
复制子目录✗ 不支持/S（不含空目录）/ /E/E（含空目录）
保留时间戳等属性✗基本保留完整保留（/COPY:DAT 可细调）
断点续传✗✗/Z
多线程加速✗✗/MT:16
镜像同步（可删除多余）✗✗/MIR
排除文件/目录✗/EXCLUDE: 列表文件/XF /XD 直接写
失败自动重试✗✗/R:n /W:n
适合场景拷一两个文件维护老脚本备份、同步、大批量——微软官方推荐
☠ 安全警示（命令行没有后悔药）：
① 命令行删除不进回收站——del 和 rd /s /q 删掉就没了，资源管理器那套"右键还原"救不回来；
② del /q 是"免确认删除"，配合通配符 del /q *.jpg 一秒清空一批，手抖就是事故；
③ rd /s /q 目录 连目录带里面所有东西瞬间蒸发，删错盘符（如 rd /s /q D:\ ）神仙难救；
④ 保命口诀：删前先 dir 确认——先 dir 备份\*.docx 看清楚要删的是哪些，再换 del。

🎯 本阶段动手任务（回到你的真电脑）

1. 在 D 盘建 D:\练习，把互动 1 的 ①→⑨ 全部在真终端做一遍（用自己建的练习目录，别碰系统目录）；

3. 在下载目录试 dir *.jpg /o:s 和 dir /b /s *.tmp，感受通配符 + 排序；
4. 建个 秘密.txt，attrib +h 藏起来，再用 dir /a 找回——体会隐藏属性不是加密。
