实战项目营 —— 五个真刀真枪的项目

九个阶段学的命令在这里拧成一股绳。每个项目都有目标 / 用到的技能 / 分步提示 / 参考实现——先自己写，卡住了再看参考。做完 5 个，这门课就真正毕业了。

项目营守则：① 所有实验在 C:\练习 里做；② 参考脚本是"参考"，抄之前先合上眼睛想 10 秒自己怎么写；③ 每个项目的通关标准在参考实现下方——达到标准再打卡。
1

一键电脑体检.bat

双击一次，电脑的"体检报告"自动生成并打开。给爸妈的电脑做维护时，让他们双击这个就行——这是命令行孝心的样子。

stage1 终端 stage2 输出重定向 stage5 体检命令 stage7 %~dp0

分步提示（先自己想，卡住再展开）

① 脚本开头 cd /d %~dp0 定位到脚本旁；② 建报告目录 md 体检报告 2>nul；③ 每条命令用 >> 追加进同一个 txt；④ 顶上写 echo 体检时间：%DATE% %TIME%；⑤ 最后 start 报告.txt 自动打开。

@echo off
cd /d %~dp0
md 体检报告 2>nul
set R=体检报告\体检-%DATE:~0,10%.txt
echo ================= 电脑体检报告 =================> "%R%"
echo 时间：%DATE% %TIME%>> "%R%"
echo.【系统】>> "%R%" & systeminfo | findstr /c:"OS" /c:"内存">> "%R%"
echo.【网络】>> "%R%" & ipconfig | findstr "IPv4 网关">> "%R%"
echo.【磁盘】>> "%R%" & wmic logicaldisk get caption,freespace,size>> "%R%"
echo.【电池】>> "%R%" & powercfg /batteryreport /output "%~dp0体检报告\电池.html" >nul
start "" "%R%"
start "" "体检报告\电池.html"
echo 体检完成，报告已打开 ✓
pause

通关标准：在自己电脑跑通，报告里能看到 IP、剩余空间和电池健康；把脚本发给朋友，对方双击也能用（这就是 %~dp0 的意义）。

2

日志分析流水线

一个 50MB 的 app.log，找出所有 ERROR、按时间排序、统计谁报得最多、输出成报告。纯管道流，不加任何软件。

stage3 管道 stage3 findstr 专题 stage7 for /F

分步提示

① 先 findstr /n "ERROR" app.log 看有多少行；② 想按行号排序就 | sort；③ 统计条数：findstr /c:"ERROR" app.log | find /c /v ""；④ 抽出"哪几个模块在报错"：for /F 逐行拆第 3 列再 sort 找重复；⑤ 全程 > 报告.txt 留档。

:: 1) 把 ERROR 行抽出来（带行号）存档
findstr /n /c:"ERROR" app.log > 错误清单.txt

:: 2) 总数统计
find /c /v "" < 错误清单.txt

:: 3) 拆出报错模块（假设第3列是模块名，逗号分隔），统计谁最吵
for /f "tokens=3 delims=," %%m in (错误清单.txt) do @echo %%m>> 模块统计.txt
sort 模块统计.txt

:: 4) 只看今天的错误（行首有日期 2026-10-26）
findstr /b /c:"2026-10-26" 错误清单.txt > 今日错误.txt

通关标准：四条流水线都能跑通；能不看提示说出每条命令"输出什么、被谁接住、加工成什么"。这就是阶段③那句"数据加工厂"的毕业考。

3

照片批量整理器

一个塞了 2000 张照片视频的"下载"文件夹：按扩展名分流到 照片/视频/截图/其他 四个子目录，再把照片按日期前缀改名。通配符 + robocopy + 延迟变量的综合演出。

stage2 robocopy stage2 通配符 stage7 for /F + 延迟展开

分步提示

① 四个 md 建目录；② robocopy 按通配符分流：*.jpg *.jpeg *.png *.heic → 照片，*.mp4 *.mov → 视频…；③ 用 robocopy /l 先"演习"一遍只列出不真的搬；④ 改名环节用 for + 延迟展开拼新名字；⑤ 最后 dir /b 检查各目录。

@echo off
setlocal enabledelayedexpansion
cd /d %~dp0
md 照片 视频 截图 其他 2>nul

robocopy . 照片  *.jpg *.jpeg *.png *.heic /mov /njh /njs >nul
robocopy . 视频  *.mp4 *.mov *.avi          /mov /njh /njs >nul
robocopy . 截图  截图* 屏幕截图*            /mov /njh /njs >nul
robocopy . 其他  *                          /mov /njh /njs >nul

:: 照片统一改名：照片-序号.jpg（延迟展开做计数器）
set /a n=1000
for %%f in (照片\*.*) do (
    set /a n+=1
    ren "%%f" "照片-!n:~1!.%%~xf"
)
echo 整理完成 ✓  照片 %n% 起 / 其余按类型分流
pause

⚠ 两次提醒：/mov 是搬移（删原件），先拿 /l 参数空跑一遍看清单；"其他"兜底规则会搬走 bat 自己——把本脚本放在整理目标外面。通关标准：整理 50 个混合测试文件全部分流成功、照片序号连续、原件无残留。

4

C 盘空间营救

C 盘飘红是每个人都遇到过的绝境。这个项目做一张"营救清单"：从安全到狠招排序，一条条执行，每一步都知道在删什么。

stage5 cleanmgr stage9 du stage8 红线意识 stage9 mklink 搬家

营救清单（按威力/风险排序，从上往下执行）

第 1 级（无风险）：du 或 tree 找大头 → 存储感知清临时文件 → cleanmgr /d C: 勾选"Windows 更新清理"（往往一次几个 GB）。

第 2 级（低风险）：清 %TEMP% 里 30 天以上的老文件（forfiles /D -30）；compact /compactos:always 开系统级压缩（省 2GB+）；移动 微信/QQ 聊天记录目录到 D 盘。

第 3 级（要动脑）：mklink /J 把大型软件目录"搬家"到 D 盘（四步法见下）；卸载重装到 D 盘。

红线：手动删 C:\Windows 下任何东西、删 System Volume Information（还原点）、删除 pagefile.sys——都不行。

:: ① 找出谁最占空间（Sysinternals du，或用 PowerShell 一行）
du -nobanner C:\Users\you | sort /r

:: ② 清 30 天以上的临时文件（先 /l 演习，去掉 /l 真删）
forfiles /p "%TEMP%" /s /d -30 /c "cmd /c echo @path"

:: ③ 开启系统压缩（NTFS 原生，省 2GB+，性能几乎无损）
compact /compactos:always

:: ④ 大目录搬家四步法（以 C:\某软件 为例）
robocopy "C:\某软件" "D:\某软件" /e /copyall
ren "C:\某软件" "某软件-旧"
mklink /j "C:\某软件" "D:\某软件"
::   验证软件正常运行后：rd /s /q "C:\某软件-旧"

通关标准：实救一次自己或朋友的 C 盘，释放 ≥ 5GB，全程没有动用任何"清理大师"软件——并用一句话向对方解释 mklink /j 为什么"程序无感知"。

5

每天 18:00 自动备份（毕业设计）

综合毕业考：robocopy 脚本 + 日志 + 计划任务 + errorlevel 收尾，一条链。做完这个，前面九个阶段就串成一个作品了。

stage7 批处理 stage7 errorlevel stage5 schtasks stage2 robocopy /MIR

分步提示

① 写 auto-backup.bat：定义 源/目标 两个变量置顶方便改；② robocopy /mir /r:2 /w:3 /xd 排除 node_modules；③ 输出 tee 进日志（bat 没有 tee，先 > 再 findstr 转屏）；④ errorlevel 判断：robocopy ≤7 都算好；⑤ schtasks 挂 18:00 每日任务，再 /run 实测一次；⑥ 一周后翻日志检查。

:: ===== auto-backup.bat =====
@echo off
set SRC=%USERPROFILE%\Documents\重要资料
set DST=D:\自动备份\重要资料
set LOG=%~dp0backup-%DATE:~0,10%.log

echo [%DATE% %TIME%] 开始备份 > "%LOG%"
robocopy "%SRC%" "%DST%" /mir /r:2 /w:3 /xd node_modules /njh >> "%LOG%"
if %errorlevel% gtr 7 (
    echo [%TIME%] 备份异常，退出码 %errorlevel% >> "%LOG%"
    exit /b 1
)
echo [%TIME%] 备份完成 ✓（退出码 %errorlevel%，7以内=正常）>> "%LOG%"
exit /b 0

:: ===== 一次性挂载计划任务（管理员） =====
schtasks /create /tn "每日自动备份" /tr "C:\tools\auto-backup.bat" ^
         /sc daily /st 18:00
schtasks /run   /tn "每日自动备份" &:: 立即试跑一次
schtasks /query /tn "每日自动备份"

两个彩蛋考点：① /mir 是镜像——源里删了目标也删，所以 D:\自动备份 里别手动存东西；② %DATE% 的截取位数随系统区域设置不同而不同，跑一下 echo %DATE% 确认自己的格式。通关标准：任务每天自动跑、日志连续七天有记录、故意断开目标盘再跑一次，日志里能看到 errorlevel 报警。
