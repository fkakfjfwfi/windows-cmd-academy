互动 3 · 环境变量与 PATH 实验室（"找不到命令"的真相）

回忆阶段①的动画：系统按 PATH 环境变量里的目录逐个找程序。PATH 里没有的目录，里面的程序就"找不到"——哪怕它明明在硬盘上。下面亲手复现一次这个事故并修好它。

当前 PATH 里的目录

PATH 实验室 · 模拟终端
故事线：你把工具装进了 C:\tools，但在任何地方输 tool 都"找不到"——因为 C:\tools 不在 PATH 里。按顺序点上面的按钮修好它。

⚖ set vs setx

setsetx
作用范围仅当前终端窗口（临时）永久（写进注册表）
立即生效？✅ 是❌ 已开着的窗口看不到，重开才生效
怎么读set 变量名 或 echo %变量名%
典型用途调试、脚本内临时值装完工具往 PATH 加目录
坑关窗口就没setx PATH 会把系统+用户 PATH 合并塞进用户变量，超长被截断——改 PATH 更稳的是系统设置图形界面

📦 常用环境变量

变量指向
%USERPROFILE%C:\Users\你（你的家目录）
%APPDATA%软件配置存放地（漫游配置）
%LOCALAPPDATA%软件缓存/本机数据
%TEMP%临时文件目录，清理对象
%COMPUTERNAME%电脑名
%DATE% / %TIME%当前日期 / 时间（脚本里打日志用）
%CD%当前所在目录

用法：cd %USERPROFILE%\Desktop 一秒回桌面；脚本里 echo 备份完成于 %DATE% %TIME% >> log.txt。

互动 4 · 计划任务 schtasks：让命令半夜自己跑

想让电脑每天 23:30 自动清理垃圾？schtasks 一条命令搞定。点击命令的任意一段，看每块积木是干嘛的。

👆 点左边任意一段

计划任务三要素：干什么（/TR）、什么时候（/SC + /ST）、叫什么名（/TN）。

🔁 建好之后的三板斧

schtasks /Query  /TN "夜间清理"        &:: 查看任务状态（加 /V 看详情）
schtasks /Run    /TN "夜间清理"        &:: 立即手动跑一次（测试用）
schtasks /Delete /TN "夜间清理" /F     &:: 不要了，删掉（/F 免确认）

⚙ 服务管理：sc 与 services.msc

命令作用例子
sc query查服务状态（RUNNING / STOPPED）sc query Spooler（打印服务）
sc stop / sc start停 / 启服务打印机抽风？sc stop Spooler 再 start
sc config改启动类型sc config Spooler start= disabled（注意 start= 后有空格）
GUI 对照services.msc 打开服务管理器，sc 的所有操作它都能点出来（sc 需管理员）

🔑 管理员权限：哪些命令要"提档"？

需要管理员的命令为什么
sfc /scannow修复系统文件，动的是 Windows 自身
chkdsk C: /f修磁盘错误（系统盘还要安排重启时修）
net user 用户名 密码增删改用户、改密码
sc stop / sc config服务是系统级资产
netsh winsock reset重置网络组件（阶段④的处方）
怎么开管理员终端：右键开始按钮（或 Win+X）→ 选「终端(管理员)」/「Windows PowerShell(管理员)」→ UAC 弹窗点「是」。标题栏会带"管理员"字样。普通终端跑需要提权的命令，会报"拒绝访问"——先想到这一层。
☠ 红线警示（管理员终端里手别抖）：C:\Windows\System32 是系统命脉，删它=重装系统；format 是整盘格式化；网上抄的命令里有 del C:\ /s /q 这种字样的，直接关页面跑路——那是毁灭性命令。

🎯 本阶段动手任务（回到你的真电脑）

1. 打开记事本，tasklist 找到它的 PID，taskkill /PID 杀掉（安全练手对象）；
2. 用 netstat -ano | findstr :端口 完整走一遍"端口追凶"（结合阶段④）；
3. echo %PATH% 看看你的 PATH，再 where notepad 验证它在哪个目录；
4. 建一个真计划任务：每天 12:00 弹个提醒（/TR "msg * 该喝水了"），再用 /Run 触发一次、/Delete 删掉；
5. winget install 装一个你想要的软件，体验命令行装机；
6. 管理员终端跑 systeminfo > 桌面体检报告.txt。
