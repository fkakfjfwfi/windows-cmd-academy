网络诊断 —— 断网自己修

阶段目标：断网不慌，用"四级 ping"定位问题出在哪一层；看懂 ipconfig / netstat / tracert 输出的每一行；端口被占会追凶。

互动 1 · 网络排障决策树（四级 ping 定位法）

这是网管都在用的排查思路：从里到外，逐层排除——先测自己，再测路由器，再测外网，最后测域名解析。哪一层断的，处方就开在哪一层。先选一个"故障剧本"，再逐关执行。

🎭 故障剧本（可随时切换）

为什么是这个顺序？127.0.0.1 是"自己打给自己"的环回地址，完全不经过网卡和网线；192.168.1.1 是家里路由器（网关）；223.5.5.5 是外网真实 IP（阿里公共 DNS，直连 IP 不经过域名解析）；www.baidu.com 则要走完整的 DNS 解析。哪一关开始失败，问题就锁死在哪一层。

互动 2 · 命令输出速读卡（每一行都是情报）

四个网络必看命令的真实输出（教育版模拟数据）。点击任意一行，右侧告诉你这一行在说什么。

👆 点左边任意一行

这些命令的输出初看像天书，其实是格式化的情报表。学会逐行读，断网时你就有了"透视眼"。

互动 3 · 谁占了我的 8080？（连环追凶三步曲）

跑个本地服务，报错"端口被占用"？这是每个开发者都会遇到的名场面。跟着三步走，30 秒揪出真凶。点「开始追凶」逐步执行。

端口追凶 · 模拟终端

常用网络命令参数速览

命令干什么常用姿势
ping测连通性和延迟ping -t baidu.com 持续 ping（Ctrl+C 停）；ping -n 4 只发 4 个包；ping -l 1024 改包大小测大包
tracert追踪到目标经过的每一跳路由tracert -d baidu.com（-d 不解析主机名，快很多）
ipconfig看/管本机 IP 配置/all 全部详情；/release + /renew 重新租 IP；/flushdns 清 DNS 缓存
nslookup查域名解析出哪个 IPnslookup baidu.com；指定 DNS 查：nslookup baidu.com 223.5.5.5
netstat看本机所有网络连接netstat -ano | findstr :8080（-a 全部 -n 数字 -o 带 PID）
arp -a看局域网里"谁在线"（IP↔MAC 对照表）直接跑，列出同网段所有活跃设备
getmac查本机网卡 MAC 地址直接跑；配 /v 看详细信息
netsh wlanWiFi 管理netsh wlan show profile name="WiFi名" key=clear 查看已连 WiFi 的密码（关键内容一栏）
curl发 HTTP 请求（Win10 1803+ 自带）curl -I https://baidu.com 只看响应头；curl -L 跟随跳转
pathpingping + tracert 合体，统计每跳丢包率pathping baidu.com（跑得慢但信息全）
小提醒：查 WiFi 密码只能查"这台电脑连过的"；ping -t 忘了停会一直跑下去，Ctrl+C 是刹车。

知识点打卡清单

🎯 本阶段动手任务（回到你的真电脑）

1. 在真机上完整跑一遍四级 ping（127.0.0.1 → 网关 → 223.5.5.5 → baidu.com），每级截图记录延迟；
2. ipconfig /all 找出你家网关、DNS、本机 MAC，对照速读卡读一遍；
3. 故意起个占 8080 端口的程序，用三步追凶把它找出来（别乱杀系统进程）；
4. 查一个你已经连过的 WiFi 密码：netsh wlan show profile name="名字" key=clear；
5. tracert baidu.com 数一数到百度要几跳。
