阶段目标：能自信地打开终端，看懂任何一条命令的结构，知道系统是怎么"听懂"你说话的。

互动 1 · 三个"黑窗口"，到底是什么关系？

新手最常混的概念。点击下面三个标签，一句话说清谁是谁。微软官方的说法：Command shell（CMD）是 Windows 最早的 shell，PowerShell 是它的升级换代产品，在 PowerShell 里 CMD 命令照样能跑，反过来不行。

CMD（cmd.exe）—— 老爷爷，但到处都有它

1987 年 DOS 时代一路沿用至今。凡是网上教程说"打开 cmd / 命令提示符"，就是它。优点：到处都有、兼容一切老教程；缺点：只能跑 Windows 命令，不懂 PowerShell 的 cmdlet（如 Get-Process），文本处理能力弱。

C:\Users\you> Get-Process 'Get-Process' 不是内部或外部命令，也不是可运行的程序或批处理文件。

互动 3 · 模拟终端（可以打字！）

这是一个装在网页里的迷你 CMD，内置一块虚拟硬盘。点击黑窗口底部的输入行，像真的一样敲命令：试试 dir、cd 练习、type todo.txt、tree、cd D:\备份 再输 d:。不会玩就输 help。

🔑 挑战卡壳了？点开看提示

挑战 1：cd 练习 进目录，再 type todo.txt。

挑战 2：cd \ 回到 C 盘根目录，dir /a（/a = 显示含隐藏在内的所有文件）。

挑战 3：cd D:\备份 会发现"纹丝不动"——跨盘符要 cd /d D:\备份，或者先敲 d: 换盘。

挑战 4：cd \ 后 tree。再来一发 ipconfig、ping baidu.com 看模拟输出。

⌨ 键盘技巧

Tab 自动补全文件/目录名（按多次轮换）——手不酸的秘密；
↑↓ 翻历史命令；
F7 弹出历史列表；
Esc 清空当前行；
Ctrl+C 中止正在跑的命令。

🖱 窗口技巧

右键=粘贴（别再找 Ctrl+V）；
标记选中后回车=复制；
cls 清屏；
Win+. 打开 emoji 面板（注释卖萌可用）；
在文件夹地址栏直接输 cmd 回车 = 在该目录打开终端。

🆘 求助技巧

任何命令后面加 /? 看官方说明书，例如 robocopy /?；
help 列出常用命令；
报错先读原文，90% 的报错直接告诉了原因。

🎯 本阶段动手任务（回到你的真电脑）

1. 用 Win+R 输 cmd、Win+X 菜单、文件夹地址栏输 cmd 三种方式各打开一次终端；
2. 在模拟终端里完成上面 4 个挑战，然后回真终端把同样的操作做一遍；
3. 分别执行 where robocopy 和 where dir，观察外部程序找得到、内部命令找不到——亲手验证动画课堂的内容；
4. 随便挑一条命令（比如 xcopy /?）读完它的帮助第一屏。
