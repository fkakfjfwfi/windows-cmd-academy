终端生态与效率 —— 老手的日常

阶段目标：Windows Terminal 玩转分屏与配置、系统自带的 SSH / TAR / CURL 上手、15 条冷门宝藏命令收入囊中、认识微软官方的"瑞士军刀" Sysinternals。

互动 1 · Windows Terminal 配置台（Ctrl+, 万物皆可配）

Win11 已是默认终端，Win10 商店安装。点每个技巧看怎么用——这些是官方文档里的精华。

⚙ settings.json 万能片段（Ctrl+, → 打开 JSON 文件）

"profiles": {
    "defaults": {
        "startingDirectory": "%USERPROFILE%\\Desktop",  // 默认从桌面开始，别再 cd 了
        "font": { "size": 12 },
        "opacity": 92, "useAcrylic": true                // 半透明毛玻璃
    }
},
"actions": [
    { "keys": "ctrl+shift+space", "command": { "action": "splitPane", "split": "auto" } }  // 一键智能分屏
]

互动 3 · 系统内置现代三件套：SSH / TAR / CURL

别再以为 Windows 的命令行只能管本地——Win10 1809+ 起内置了 OpenSSH 客户端、tar 归档和 curl 传输。三张卡各点开看一次。

🔐 SSH 远程登录

ssh user@192.168.1.20        &:: 登录 Linux 服务器
ssh -p 2222 user@host        &:: 指定端口
scp file.txt user@host:/tmp  &:: 远程拷文件

管理树莓派、云服务器、公司 Linux 机器从此不用装 Xshell。配合 C:\Users\你\.ssh\config 可以给主机起别名一键连。

📦 TAR 打包解包

tar -a -c -f 备份.zip 目录   &:: 按扩展名自动选格式
tar -xf 备份.zip             &:: 一行解开（自动识别格式）
tar -czf 备份.tgz 目录       &:: 标准 Linux 风格

-a = 看扩展名自动选 zip/tar.gz。给同事发一堆文件、脚本里打包日志，不用再装 7-Zip 命令行版。

🌐 CURL 万能传输

curl -I https://example.com  &:: 只看响应头
curl -O 网址                 &:: 下载文件（保留文件名）
curl -o 输出名 网址          &:: 下载并改名

脚本里下载安装包、测试接口通不通。配合 curl -I | findstr HTTP 就是极简测活。

互动 4 · Sysinternals：微软官方的命令行瑞士军刀

1996 年由 Mark Russinovich 写的工具套件，2006 年被微软收编，免费、免安装、命令行为主。SS64 A-Z 里那一串 Ps 开头的命令就是它们。获取：微软商店搜 Sysinternals Suite，或直接访问 live.sysinternals.com。

工具干什么什么时候用它而不是普通命令
psexec在远程/本机以 SYSTEM 身份执行程序需要比管理员更高的 SYSTEM 权限排查服务；psexec -s -i cmd 开个 SYSTEM 终端长长见识
procdump进程崩溃/高 CPU 时自动抓转储程序闪退找不出原因时，procdump -e -ma 应用名 抓崩溃现场给开发者
psping测端口延迟/带宽ping 通但服务连不上？psping 主机:443 直接测端口层
accesschk查"谁能访问什么"icacls 说得含糊时，它直接列出某用户对文件/注册表/服务的实际权限
streams列出 NTFS 附加数据流（ADS）怀疑文件"从网上来被拦截"？streams 文件 能看到 Zone.Identifier 标记
sigcheck查文件签名与 VirusTotal 状态怀疑某个 exe 是伪装的：一行查数字签名是否有效
du统计目录占用大小C 盘爆了想找"谁最肥"，比资源管理器右键属性快得多
coreinfoCPU 拓扑细节（核/缓存/NUMA）性能调优时看哪些核共享缓存
记忆方法：P 系（PsExec/PsPing/PsList…）管进程与远程，无 P 系（AccessChk/Streams/DU…）管文件与系统细节。全部免费免安装，解压即用。

互动 5 · doskey 宏实验室（给自己造命令）

doskey 不只是看历史（阶段①教过 /history）——它能把长命令定义成你自己的短命令。点按钮体验宏的定义与展开。

doskey 宏实验室 · 模拟终端
宏是一次性的：关窗口就没。想永久生效，把 doskey 行写进 CMD 的自启动（注册表 HKCU\Software\Microsoft\Command Processor 的 AutoRun 值指向你的宏文件）——这正是 reg 命令的实战场景。

✅ 阶段⑨ 打卡清单（勾满 6 项才算通关）

🛠 动手任务（回到真电脑）

任务：搭建你的"效率终端"——五件事做完，终端就是为你定制的：

① 安装/打开 Windows Terminal，设为默认终端；
② settings.json 里把 startingDirectory 指向工作目录；
③ 建宏文件 C:\tools\alias.cmd（内容几行 doskey），AutoRun 指向它；
④ 用 ssh -V / curl --version / tar --version 确认三件套在位；
⑤ Sysinternals 解压进 C:\tools\sysinternals 并加进 PATH。

做完后打开终端就是"随时可干活"状态——这是老手和新手的肉眼区别。
