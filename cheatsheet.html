① 文件与目录

命令作用示例
cd 目录切换目录；cd .. 回上级，cd /d D:\工具 跨盘符cd C:\Users\you\Desktop
pushd / popd跳转并记住来路 / 一秒跳回（目录栈，支持网络路径自动映射盘符）pushd D:\项目 … popd
subst X: 目录给深层目录发虚拟盘符；subst X: /d 删除（无需管理员）subst W: C:\深层\嵌套\工作目录
dir列目录内容；/a 含隐藏，/o:s 按大小，/s 含子目录，/b 只列名字dir /a /o:s C:\下载
tree /f树状展示目录（/f 连文件一起）tree /f C:\项目
md / mkdir新建目录（可一次建多级）md C:\备份\2026\照片
rd /s /q删整个目录树（/s 连内容，/q 免确认）；⚠ 不进回收站不可逆rd /s /q C:\临时垃圾
copy 源 目标复制文件（不支持目录树）copy 报告.docx D:\备份\
xcopy /e /i复制目录树（/e 含空目录，/i 目标当目录）xcopy C:\网站 D:\备份\网站\ /e /i
robocopy 源 目标 /e最强复制；/MIR 镜像（会删多余文件！）、/xo 只拷新文件、/mt:16 多线程、/z 断点续传、/r:2 /w:3 重试；退出码 ≤7 都算成功robocopy "C:\我的 文件" D:\备份 /mir /r:2 /w:3
forfiles按条件批量处理文件：/D -30 三十天前、/S 递归、/C 命令forfiles /p %TEMP% /d -30 /c "cmd /c del @path"
del /f /q 文件删文件；del *.tmp /s 递归删一类。⚠ 不进回收站，慎用del C:\日志\*.log /f /q
ren 旧 新重命名（同目录内）；支持通配符批量改扩展名ren *.jpeg *.jpg
move 源 目标移动 / 跨目录改名move 散图\*.jpg D:\相册\
type 文件打印文本文件内容type config.txt
attrib +h 文件改属性：+h 隐藏 / -h 取消，+r 只读；/s 递归attrib +h 密码本.txt
compact /compactos:alwaysNTFS 原生压缩省空间（C 盘营救第一狠招，性能几乎无损）compact /compactos:query 先查状态
defrag C: /o碎片整理（/o 对 SSD 做优化重排而非碎片整理）defrag C: /o
mklink /d /j符号链接（/d）/ 目录联接（/j，无需管理员场景更宽松）；C 盘搬家四步法核心mklink /j "C:\某软件" "D:\某软件"
通配符* 任意长字符，? 恰好一个字符dir 报告-*.docx / del ???.tmp

② 文本与管道

命令 / 符号作用示例
命令A | 命令B管道：把 A 的输出接给 B 当输入type server.log | findstr ERROR | sort
> 文件输出重定向（覆盖写）dir /b > 清单.txt
>> 文件输出重定向（追加写）echo 完成 %DATE% >> log.txt
2> 文件只把错误输出写进文件build.exe 2> err.txt
2>&1错误流合并进正常流build.exe > all.log 2>&1
>nul丢弃输出（黑洞）；常配 2>nulping -n 1 主机 >nul 2>nul
< 文件把文件内容当命令输入sort < 名单.txt
findstr "词"按关键词筛行；/i 忽略大小写 /v 反选 /n 行号 /b 行首 /e 行尾 /c:"整个短语" /s 递归子目录ipconfig /all | findstr /i "dns"
find /c /v ""经典组合：统计行数（/c 计数，/v "" 反选空串=全要）findstr ERROR app.log | find /c /v ""
more分页看长文本（空格翻页，Q 退出）type 长日志.txt | more
sort排序；/r 反向sort 成绩.txt
fc 文件1 文件2比较两个文件差异fc 旧配置.txt 新配置.txt
clip把输出送进剪贴板ipconfig /all | clip
echo %errorlevel%看上一条命令退出码（0 = 成功）；robocopy ≤7 都算好robocopy … && echo 成功

③ 网络诊断

命令作用示例
ping 地址测连通性；-t 不停测（Ctrl+C 停）、-n 3 只测 3 次、-4 强制 IPv4ping -n 3 www.baidu.com
ipconfig /all看网卡全貌：IP、网关、DNS、MAC；/flushdns 清 DNS 缓存；/release + /renew 重新要 IPipconfig /all
tracert 地址逐跳追踪路径，定位断在哪一跳；-d 不解析域名更快tracert -d www.baidu.com
nslookup 域名查 DNS 解析结果（域名 → IP）nslookup github.com
netstat -ano看端口占用：-a 全部 -n 数字 -o 带 PID；配合 tasklist | findstr PID 找真凶netstat -ano | findstr :8080
pathping 地址ping + tracert 合体，统计每跳丢包率（较慢）pathping www.baidu.com
arp -a看局域网内"IP ↔ MAC"邻居表arp -a
getmac列出本机 MAC 地址getmac /v
curl 地址发 HTTP 请求；-I 只看响应头，Win10 1803+ 自带curl -I https://example.com
pktmon start --captureWin10 2004+ 内置抓包；etl2pcap 转 Wireshark 格式pktmon etl2pcap 抓包.etl -o 抓包.pcapng
netsh wlan show profile列出连过的 Wi-Fi；加 name="名" key=clear 看明文密码（需管理员）netsh wlan show profile name="家里WiFi" key=clear
排障顺序ping 网关 → ping 公网 IP → ping 域名 → 看 DNS；逐级缩小范围（阶段④决策树）

⑦ 批处理专用（bat 写作全套零件）

for 五种形态（bat 里写 %%i，命令行手敲写 %i）

写法作用示例
for %i in (列表) do …遍历列表 / 通配符文件for %i in (*.jpg) do @echo %i
for /d %i in (路径\*) do …只遍历目录for /d %i in (C:\练习\*) do @echo %i
for /r 根 %i in (*.log) do …递归钻子目录找文件for /r %i in (*.tmp) do @del "%i"
for /l %i in (1,1,100) do …数字循环（起点,步长,终点；负步长倒着数）for /l %i in (1,2,9) do @echo %i
for /f "tokens=1-3 delims=," %a in (文件) do …按分隔符拆字段解析文本；%a 起自动分配 %b %c…；('命令') 可直接解析命令输出for /f "tokens=1 delims=," %a in (名单.csv) do @echo %a

变量与字符串（%var% 快照 / !var! 实时）

写法作用示例
setlocal enabledelayedexpansion开启延迟展开（循环里要用变化值必开；附带不污染环境的副作用）脚本头部标配
!var!实时取值（%var% 是"读入行时"的快照——for 括号块整块读入，循环内 %var% 永远是旧值）for … do (set /a n+=1 & echo !n!)
set /a 算式数学计算（+ - * / 及赋值连写）set /a count+=1
%var:~起点,长度%字符串截取（负数=从尾部数）%v:~0,3% / %v:~-4%
%var:旧=新%字符串全量替换（区分大小写）ren "%f" "%f: =_%"（空格换下划线）
%1 %~1 %~dp0接收参数 / 去引号 / 脚本自己所在目录（绿色便携脚本灵魂，第一行 cd /d %~dp0）type "%~dp0config.txt"
%~f1 %~n1 %~x1参数拆解：绝对路径 / 主名 / 扩展名（%%~xf 同理用于 for 变量）ren "%%f" "照片-!n!.%%~xf"

流程控制

写法作用示例
if errorlevel 1退出码 ≥1 成立（老写法）；现代写法 if %errorlevel%==0，延迟场景用 !errorlevel!if errorlevel 1 (echo 失败 & exit /b 1)

命令作用示例
doskey 宏=命令 $*自定义短命令（会话内有效；写进 AutoRun 注册表可永久）doskey ll=dir /o:n $*
doskey /history列出本次会话历史（> 导出成文档）doskey /history > 操作记录.txt
title 窗口名改窗口标题（多窗口救命细节）title 备份任务 · 不要关
color 0A改配色（背景+前景）；不带参数还原color /? 看色表
choice /c YN /m 提示脚本交互确认；timeout /t 10 /nobreak 定时等待危险操作前问一句
msg 用户名 "内容"给本机/局域网会话弹消息框msg %username% "该喝水了"
eventcreate /l APPLICATION /so 来源 /id 100 /d "内容"脚本往事件日志留痕（配 wevtutil 查）脚本运行历史官方存档
tzutil /g / /s "UTC"查 / 切时区跨时区脚本对时
whoami /groups | findstr "12288"判断当前是否管理员提权（SID 12288 = Administrators）whoami /user 看账户
openfiles /query列出共享中被打开的文件（先 /local on 重启生效）"文件删不掉"元凶抓捕器
freedisk C:查剩余空间（脚本里做"低于阈值自动清理"）freedisk C:
wusa /uninstall /kb:编号 /quiet精准卸载某个 Windows 更新（配 wmic qfe list 查编号）补丁搞坏系统的后悔药
gpupdate /force立即刷新组策略；gpresult /r 看生效策略改完策略不等注销
assoc / ftype查改扩展名关联（assoc .md 看类型 → ftype 类型 看打开方式）双击打开方式被劫持时的修法
iexpress把脚本打包成自解压 exe（系统自带向导）给不会命令行的人发工具
