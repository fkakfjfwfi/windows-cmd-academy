① 文件与目录

命令作用示例
cd 目录切换目录；cd .. 回上级，cd /d D:\工具 跨盘符cd C:\Users\you\Desktop
dir列目录内容；/a 含隐藏，/o:s 按大小排序，/s 含子目录，/b 只列名字dir /a /o:s C:\下载
tree /f树状展示目录（/f 连文件一起）tree /f C:\项目
md / mkdir新建目录（可一次建多级）md C:\备份\2026\照片
rd /s /q删整个目录树（/s 连内容，/q 免确认）；小心不可逆rd /s /q C:\临时垃圾
copy 源 目标复制文件（不支持目录树）copy 报告.docx D:\备份\
xcopy /e /i复制目录树（/e 含空目录，/i 目标当目录）xcopy C:\网站 D:\备份\网站\ /e /i
robocopy 源 目标 /e最强复制；/MIR 镜像（会删多余文件！）、/xo 只拷新文件、/mt:16 多线程、/r:2 /w:3 失败重试robocopy "C:\我的 文件" D:\备份 /mir /r:2 /w:3
del /f /q 文件删文件；del *.tmp /s 递归删一类。回收站都不进，慎用del C:\日志\*.log /f /q
ren 旧 新重命名（同目录内）ren 报告-v1.docx 报告-final.docx
move 源 目标移动 / 跨目录改名move 散图\*.jpg D:\相册\
type 文件打印文本文件内容type config.txt
attrib +h 文件改属性：+h 隐藏 / -h 取消，+r 只读attrib +h 密码本.txt
mklink建符号链接 /d 目录链接 /j junction，需管理员mklink /d D:\链接 C:\真实目录
通配符* 任意长字符，? 恰好一个字符dir 报告-*.docx / del ???.tmp

② 文本与管道

命令 / 符号作用示例
命令A | 命令B管道：把 A 的输出接给 B 当输入type server.log | findstr ERROR | sort
> 文件输出重定向（覆盖写）dir /b > 清单.txt
>> 文件输出重定向（追加写）echo 完成 %DATE% >> log.txt
2> 文件只把错误输出写进文件build.exe 2> err.txt
2>&1错误流合并进正常流build.exe > all.log 2>&1
>nul丢弃输出（黑洞）；常配 2>nulping -n 1 主机 >nul 2>nul
< 文件把文件内容当命令输入sort < 名单.txt
findstr "词"按关键词筛行；/i 忽略大小写 /v 反选 /n 显示行号 /b 行首 /e 行尾 /c:"整个短语"ipconfig /all | findstr /i "dns"
more分页看长文本（空格翻页，Q 退出）type 长日志.txt | more
sort排序；/r 反向sort 成绩.txt
fc 文件1 文件2比较两个文件差异fc 旧配置.txt 新配置.txt
clip把输出送进剪贴板ipconfig /all | clip
echo %errorlevel%看上一条命令退出码（0 = 成功）；robocopy ≤7 都算好robocopy … && echo 成功

③ 网络诊断

命令作用示例
ping 地址测连通性；-t 不停测（Ctrl+C 停）、-n 3 只测 3 次、-4 强制 IPv4ping -n 3 www.baidu.com
ipconfig /all看网卡全貌：IP、网关、DNS、MAC；/flushdns 清 DNS 缓存；/release + /renew 重新要 IPipconfig /all
tracert 地址逐跳追踪路径，定位断在哪一跳；-d 不解析域名更快tracert -d www.baidu.com
nslookup 域名查 DNS 解析结果（域名 → IP）nslookup github.com
netstat -ano看端口占用：-a 全部 -n 数字 -o 带 PID；配合 tasklist | findstr PID 找真凶netstat -ano | findstr :8080
pathping 地址ping + tracert 合体，统计每跳丢包率（较慢）pathping www.baidu.com
arp -a看局域网内"IP ↔ MAC"邻居表arp -a
getmac列出本机 MAC 地址getmac /v
curl 地址发 HTTP 请求；-I 只看响应头，Win10 1803+ 自带curl -I https://example.com
netsh wlan show profile列出连过的 Wi-Fi；加 name="名" key=clear 看明文密码（需管理员）netsh wlan show profile name="家里WiFi" key=clear
排障顺序ping 网关 → ping 公网 IP → ping 域名 → 看 DNS；逐级缩小范围（阶段④决策树）

④ 进程与服务

命令作用示例
tasklist列进程；/v 详细，按名过滤 | findstr /i chrometasklist | findstr node
taskkill /pid 号 /f按 PID 强杀（/f 强制，卡死必备）；/t 连子进程一起taskkill /pid 12345 /f
taskkill /im 名 /f按映像名杀（殃及所有同名进程，如全部 chrome）taskkill /im notepad.exe /f
sc query 服务名查服务状态（RUNNING / STOPPED），需管理员sc query Spooler
sc stop / start停 / 启服务（打印机抽风就重启 Spooler）sc stop Spooler
sc config 服务 start= disabled改启动类型；注意 start= 等号后有空格sc config Spooler start= auto
services.msc图形版服务管理器，sc 能做的它都能点Win+R 输入 services.msc
shutdown /s /t 0关机（/r 重启，/a 取消倒计时，/t 秒数）shutdown /r /t 60
红线提醒System(PID 4)、csrss、wininit 等系统关键进程杀不得；杀错轻则蓝屏重则无法开机

⑤ 系统信息与维护

命令作用示例
systeminfo一页看全：系统版本、内存、补丁、开机时间、网卡systeminfo | findstr /i "内存 OS"
sfc /scannow扫描修复系统文件（🔒 管理员）系统文件损坏 / 蓝屏后先跑它
chkdsk D: /f查修磁盘错误（🔒 系统盘要安排重启时修）chkdsk D: /f
driverquery列驱动程序清单driverquery | more
powercfg /batteryreport生成电池健康报告（笔记本，看实际容量 vs 设计容量）报告在当前目录 battery-report.html
powercfg /energy60 秒能耗体检，揪出费电后台（🔒）powercfg /energy
cleanmgr磁盘清理（/sagerun:1 一键清预设项）cleanmgr /d C:
dxdiag DirectX 诊断：显卡 / 声卡 / 输入设备排查游戏画面问题第一步
ver / vol / hostname系统版本 / 卷标序列号 / 计算机名，一条一个答案ver

⑥ 计划任务与环境变量

schtasks 三要素：干什么 /TR、什么时候 /SC + /ST、叫什么 /TN

命令作用示例
schtasks /create …建计划任务；/sc daily|weekly|minute /st 时间 /tr 要跑的命令schtasks /create /tn "夜间清理" /tr "C:\tools\清理.bat" /sc daily /st 23:30
schtasks /query /tn 名查任务状态（/v 详情，/fo list 好读）schtasks /query /tn "夜间清理"
schtasks /run /tn 名立即手动跑一次（测试用）建完必跑一次验证
schtasks /end /tn 名停掉正在跑的任务schtasks /end /tn "夜间清理"
schtasks /delete /tn 名 /f删任务（/f 免确认）schtasks /delete /tn "夜间清理" /f

环境变量

命令作用示例
set 变量=值临时设变量（只活在本窗口）set PORT=8080
set列出全部 / 按前缀筛（set p）set path
setx 变量 值永久写注册表；已开的窗口看不到，重开才生效；改 PATH 谨慎（有合并截断坑）setx JAVA_HOME "C:\jdk-21"
echo %变量%读变量；脚本里拼路径常用cd %USERPROFILE%\Desktop
where 程序名看命令到底命中 PATH 里哪个 exe（"找不到命令"排查神器）where python
start 程序/文件新窗口启动程序 / 用默认程序打开文件start battery-report.html
常用变量%USERPROFILE% 家目录 · %APPDATA% 配置 · %LOCALAPPDATA% 缓存 · %TEMP% 临时 · %COMPUTERNAME% 电脑名 · %DATE% %TIME% 时间

⑦ winget 装机

命令作用示例
winget search 关键词搜软件包（认准 Source: winget 官方源）winget search python
winget install 包名安装；一条命令直达官方源，告别下载站全家桶winget install Git.Git
winget list列出已装软件（含非 winget 装的）winget list | findstr /i java
winget upgrade列出可升级项；--all 一键全升winget upgrade --all
winget uninstall 包名卸载winget uninstall 某全家桶
winget show 包名看版本 / 发布者 / 安装包细节winget show Python.Python.3.12
新装机一条龙Python → Git → VSCode → Notepad++，每条一个 winget install，最后 winget upgrade --all（阶段⑤有完整脚本）

⑧ CMD ↔ PowerShell 对照

任务CMD 写法PowerShell 写法
列目录dirGet-ChildItem（别名 ls / gci）
切目录cd 路径Set-Location（别名 cd）
看文件type 文件Get-Content（别名 cat / gc）
复制 / 移动 / 删除copy / move / delCopy-Item / Move-Item / Remove-Item（别名 cp / mv / rm）
新建目录md 目录New-Item -ItemType Directory 目录（别名 mkdir）
清屏clsClear-Host（别名 cls）
列进程tasklistGet-Process（别名 ps）
杀进程taskkill /pid 1234 /fStop-Process -Id 1234 -Force
筛文本… | findstr 词… | Select-String 词（别名 sls）
读环境变量echo %PATH%$env:PATH
看服务sc query 服务名Get-Service 服务名
网络命令ping / ipconfig / tracert / netstat 在两边都照用（PowerShell 兼容外部程序）
输出到文件dir > 清单.txtGet-ChildItem | Out-File 清单.txt（> 也通）
对象管道只有文本，靠 findstr/sort 硬切Get-Process | Sort-Object CPU -Descending | Select-Object -First 5——排序筛选的是"对象"不是字符串
在 PowerShell 里 CMD 命令几乎全能跑；反之不行。所以日常用 PowerShell 不亏，老脚本继续给 CMD。

⑨ 快捷键与技巧

按键 / 写法作用备注
Tab自动补全文件 / 目录 / 命令名最值得养成习惯的一个，少打字还防拼错
↑ ↓翻历史命令改一改重跑，不用重敲
F7弹出历史命令菜单，方向键选找十几条前的那条特别好使
Esc / Ctrl+C清空当前行 / 强停正在跑的命令ping -t 卡住就 Ctrl+C
右键老控制台里 = 粘贴（或选中即复制）属性里开「快速编辑模式」更顺手
拖文件进窗口自动填入完整路径（含引号）路径带空格不怕忘加引号
doskey /history列出本次会话历史PowerShell 里用 history
命令 /?查任何命令的官方帮助比背参数靠谱，Windows 命令通用
命令1 && 命令2前一个成功才执行后一个对应还有 ||（失败才执行）和 &（顺序执行）
Win+X → A一键开管理员终端跑 sfc / chkdsk / sc 前先提档
管理员怎么认标题栏写「管理员: 命令提示符」才是；net session 不报错也是普通窗口跑管理命令只会报「拒绝访问」
PowerShell 三板斧Get-Help 命令 -Examples 查用法 · Get-Command 关键词 找命令 · 命令 | Get-Member 看对象有什么属性方法
🎓 毕业寄语：命令行不是背出来的，是用出来的。把这页打印出来，忘什么查什么；两个星期后你会发现，大部分命令已经长在手指上了。
