系统急救与安全 —— 电脑坏了不慌

阶段目标：系统文件坏了会按官方流程修（DISM → SFC）、"拒绝访问"的文件能抢回来、注册表敢查会备、哪些命令碰不得心里有数。

互动 1 · 系统急救决策树（三大病症 × 标准处方）

选一个"病症"，按步骤执行处方。每一步都有真实输出样例和"为什么要这么做"。流程全部来自微软官方支持文档。

管理员: 命令提示符（模拟）
👆 先选病症，再一步步执行。所有修复命令都需要管理员终端。

互动 2 · "拒绝访问"抢救实验室（takeown + icacls 组合拳）

老硬盘、别人留下的系统盘、重装后的旧用户文件夹——打开就弹"你需要权限来执行此操作"。三步组合拳按顺序来，顺序错了抢不动。

📁 目标：C:\遗物\（来自旧电脑的文件夹）

管理员: 命令提示符（模拟）
故事线：从报废笔记本拆下的硬盘接到了新电脑，C:\遗物\ 里是以前的照片，双击却提示"拒绝访问"。按 ①→②→③ 顺序抢救。

互动 3 · 注册表操作台（reg 命令四板斧）

注册表是 Windows 的"系统级设置数据库"，reg 命令让你不开 regedit 也能读写它。先看安全守则，再动手。

reg 命令 · 模拟终端
安全守则：① 动任何键之前先 reg export 备份成 .reg 文件，双击即可还原；② 删除键值前再 query 确认一次路径；③ 网上"优化教程"给的 reg 文件，看懂每一行再导入——注册表没有 Ctrl+Z。

🚨 危险命令红线清单（点开看后果，终身受益）

这些命令本身没有错——运维天天用。错的是不知道它们的威力就回车。每个都点一遍，知道后果才能防患。

👆 点任意一条，看它"正常用途 / 翻车现场 / 防呆方法"。

🧰 应急工具箱（WinRE / 事件日志 / BitLocker）

🖥 WinRE 恢复环境：系统进不去时的命令行

系统连桌面都进不去？还有一层"箱子里的箱子"。三种进法：

进法操作
设置入口设置 → 系统 → 恢复 → 高级启动 → 立即重新启动
Shift 重启开始菜单 → 电源 → 按住 Shift 点"重启"
开机强断电 ×2开机能看到转圈就长按电源键强关，反复 2~3 次自动进 WinRE

疑难解答 → 高级选项 里最常用的是：启动修复（自动修引导）、系统还原（回到还原点）、命令提示符（此时你的系统盘可能是 D:，用 dir C:\ 先认路）。

bootrec /fixmbr      &:: 修主引导记录
bootrec /fixboot     &:: 重写引导扇区
bootrec /rebuildbcd  &:: 重建启动菜单
dism /image:C:\ /cleanup-image /restorehealth  &:: 离线修复系统文件

📋 事件日志与磁盘加密速查

命令作用
eventvwr打开事件查看器（图形），系统蓝屏/报错时间点全在这里
wevtutil qe System /c:5 /rd:true /f:text命令行看最近 5 条系统日志（倒序、文本格式）
wevtutil cl Application清空某个日志（清理报错噪音用，慎）
manage-bde -status看 BitLocker 加密状态（🔒 需管理员）
manage-bde -unlock D: -RecoveryPassword 111111-222222-…用 48 位恢复密钥解锁加密盘
reagentc /info看 WinRE 恢复环境是否启用
wmic diskdrive get model,status硬盘健康速览（OK / Pred Fail 预警）
蓝屏排查第一问：eventvwr 里筛"错误"，看蓝屏时间点前后的来源（磁盘 / 驱动 / 内存）。80% 的蓝屏根源是驱动或硬盘，而不是"系统坏了重装吧"。

✅ 阶段⑧ 打卡清单（勾满 6 项才算通关）

🛠 动手任务（回到真电脑）

任务：做一张"急救 U 盘"备忘卡——新建 急救.txt，把下面四行抄进去，以后系统出事照着打：

① 修复系统文件（管理员）：
   dism /online /cleanup-image /restorehealth
   sfc /scannow
② 进不去系统：强制断电3次 → 疑难解答 → 高级 → 启动修复
③ 拒绝访问：
   takeown /f "路径" /r /d y
   icacls "路径" /grant %username%:F /t
④ 查蓝屏：eventvwr → Windows日志 → 系统 → 筛选"错误"

再把它放到桌面 + 发一份到自己邮箱。真正的急救能力 = 事发时你能想起来"第一步干什么"。

📚 深入资源

微软官方 SFC 支持页——DISM → SFC 顺序的出处（support.microsoft.com 搜 "系统文件检查器"），所有第三方"修复教程"的原版。

SS64 的 icacls / bootrec / manage-bde 页面——参数比官方文档更全，带大量示例。

十一论坛（elevenforum.com）的 Command Prompt 教程版块——大量真实急救案例带完整命令输出。

CBS 日志定位法：SFC 修不了的文件，看 C:\Windows\Logs\CBS\CBS.log 里搜 "[SR]" 行，能看到具体哪个文件没修好。

通关标准：朋友电脑"开不了机/一直弹错误"，你能不百度地报出前三步该干什么。
