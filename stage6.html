互动 4 · PowerShell 脚本入门：.ps1 与"三板斧"

    

      

        
📜 .bat vs .ps1

        

          
.bat 批处理.ps1 脚本

          
            
语法CMD 老语法PowerShell（现代语言）

            
双击运行✅ 直接跑❌ 默认用记事本打开（防误触，安全设计）

            
怎么跑双击 / cmd 里输文件名右键"使用 PowerShell 运行"，或在 PS 里 .\脚本名.ps1

            
能力上限串命令、简单逻辑真编程语言：异常处理、模块、连 API

          
        

        
执行策略（第一次跑 .ps1 必遇的坎）：Windows 默认禁止运行任何脚本（防病毒）。学脚本第一步，用管理员不需要的这条放开限制：
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
含义：只改当前用户；本地脚本随便跑，从网上下载的要有签名。改完一次管一辈子。

      

      

        
🪓 自学三板斧（不用背命令的秘诀）

        
① Get-Help

          
Get-Help Get-Process -Examples

          
PowerShell 版的 /?，-Examples 直接给例题。还有 -Full 看完整手册、-Online 打开网页版。

        
② Get-Command

          
Get-Command *process*

          
"跟 process 有关的命令都有啥？"——按关键词搜命令，忘记全名时的救命稻草。

        
③ Get-Member

          
Get-Process | Get-Member

          
"这个对象身上都有什么属性、什么方法？"——对象管道的"透视镜"，看一眼就知道 .CPU、.Id 都能点。

      

    

  


  
  

    
🎓 毕业任务：写一个「一键体检.bat」

    

      
综合本课程全部知识，写一个脚本：双击运行，自动收集系统信息、网络配置、进程清单，汇总成一份体检报告。参考骨架（每一行你都已经学过了）：

      
@echo off
cd /d %USERPROFILE%\Desktop
echo === 命令行学院体检报告 %DATE% %TIME% === > 体检报告.txt
systeminfo >> 体检报告.txt
ipconfig /all >> 体检报告.txt
tasklist >> 体检报告.txt
echo 体检完成！报告已保存到 %CD%\体检报告.txt & pause

      
挑战升级：① 把它用 schtasks 建成每天自动跑的计划任务（阶段⑤）；② 把 systeminfo 换成 robocopy 给重要文件夹做备份（阶段②）；③ 用 PowerShell 重写一遍（今天的对象管道）。

      
🎓 恭喜毕业！你能打开终端、管理文件、加工文本、诊断网络、管理系统、编写脚本——这条从"黑窗口恐惧症"到"自动化自由"的路，你已经走完了。右上的「⌨ 速查表」是你的随身兵器谱，忘了就回来翻。真正的精进从现在开始：把真电脑上的重复操作，逐个变成脚本。
